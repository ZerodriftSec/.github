# Zerodrift Security GitHub Defaults

This repository contains the organization profile and shared community health files for Zerodrift Security repositories.

## Files

- `profile/README.md` - public GitHub organization profile
- `SECURITY.md` - vulnerability reporting policy
- `CONTRIBUTING.md` - contribution expectations
- `STYLE.md` - shared code style guide
- `PULL_REQUEST_TEMPLATE.md` - default PR checklist

Project-specific repositories may add stricter rules when needed.
