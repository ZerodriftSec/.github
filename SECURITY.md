# Security Policy

Zerodrift Security works on audit tooling and security research. Please do not disclose sensitive vulnerabilities through public GitHub issues.

## Reporting a Vulnerability

Email: security@zerodrift.xyz

Include:

- Affected repository and commit or release
- Clear reproduction steps
- Expected and actual behavior
- Impact assessment
- Any proof-of-concept code or screenshots

We will acknowledge reports as soon as practical and coordinate remediation before public disclosure when the issue is sensitive.

## Public Research Repositories

Some repositories intentionally contain vulnerable examples, fixtures, or exploit demonstrations. These are marked in their README as labs, fixtures, or research artifacts.
