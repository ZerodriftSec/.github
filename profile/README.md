# Zerodrift Security

Zerodrift Security researches, audits, and builds tooling for high-assurance crypto systems.

We focus on practical security review for smart contracts, protocol logic, agent-assisted audit workflows, and reproducible validation harnesses.

## What We Publish

- Public audit reports and security writeups
- Audit automation and agent skills
- Benchmarks for security-review workflows
- Test fixtures and vulnerable examples for research
- Selected product and internal tooling that is safe to open source

## Repository Map

| Area | Naming | Purpose |
| --- | --- | --- |
| Audit reports | `audits` | Public reports, portfolio, and client-approved artifacts |
| Audit tooling | `audit-*` | CLIs, workbenches, validation harnesses, and review support tools |
| Agent skills | `*-skills`, `agent-*` | Skills for agent-assisted security workflows |
| Benchmarks | `*-benchmarks` | Evaluation datasets and benchmark runners |
| Labs and fixtures | `lab-*`, `*-fixtures` | Reproducible examples, mock contracts, and research demos |
| Product surfaces | `zerodrift-*` | Zerodrift applications, websites, and docs |
